# Hi, I'm Amir

**Junior Data Analyst · Historian of Iran and the Middle East**

I moved from historical research into data analysis because both require the
same discipline: questioning sources, understanding context, documenting
assumptions, and producing conclusions that can be checked.

My academic background is in Iranian, Islamic and Jewish Studies. Working with
historical sources taught me to compare conflicting evidence, work across
languages, and distinguish what the data shows from what it does not show.

Today I apply the same approach to data.

I work mainly with **Python, SQL and Power BI**, with a particular interest in
financial, market and on-chain data. Web3 became one of my main areas of
interest because blockchain data is public, large and messy — exactly the kind
of data where careful cleaning, validation and interpretation matter.

I prefer reproducible analysis, clear documentation and explicit limitations
over impressive-looking claims.
